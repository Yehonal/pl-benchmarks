Why benchmark Euler 12?

What does it cost to process data once it arrives? While a database read is pending, asynchronous I/O lets a service handle other requests. Once the records arrive, applying a rule or updating a total still takes CPU time for every record.

Euler 12 makes that cost easy to compare. Each implementation visits the same triangular numbers and tests the same divisors in the same order. The ranking shows how long each runtime takes to execute this integer loop. Database latency and network throughput are separate measurements.

Elapsed time includes process startup and any JIT warm-up during the search. Automated runs rank fastest first, using median elapsed time from three fresh processes. Peak RAM is the median peak RSS. Each run must return 842161320.
